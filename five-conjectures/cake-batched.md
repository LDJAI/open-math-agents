# Connected mixed-cake division when each round can contain a sealed batch

**Scope.** This note proves a constructive existence result for any finite number of agents in a two-round model with batched Robertson–Webb queries. Within each round, every agent simultaneously submits its entire vector of answers, and the complete vectors then become public. The permitted scalar questions are ordinary cut and evaluation queries. Ortega and Segal-Halevi describe a public extensive form with one query to each active agent at a node. Exposing the intermediate answers of a vector creates additional strategic decision nodes. The argument below does not establish their conjecture in that original model. [Ortega and Segal-Halevi, §§3.2, 7.2](https://doi.org/10.1007/s00355-022-01416-4)

Assume $n\ge2$, with additive, finite, nonatomic signed valuations normalized to total 1. Let $F_i(x)$ denote the cumulative valuation of agent $i$. It is continuous, $F_i(0)=0$, $F_i(1)=1$. Every first crossing of $k/n$ for $1\le k<n$ exists and lies in the interior. Strictly increasing positive valuations are permitted as are signed valuations with downward excursions. A consistent deviation may be any dynamically permissible sequence of replies. Utilities at a decision node are compared by their infimum and supremum over opponents' types consistent with the public history, as in the definition of non-obvious manipulability (NOM).

## Protocol

Fix $n$ distinct public interior probe points.

1. Each agent reports, in a sealed vector, her first prefix cut at each $k/n$ for $k=1,\ldots,n-1$ and her prefix evaluation at each fixed probe. A negative evaluation $v$ proposes the cut coordinate $\exp(v)$, which is in $(0,1)$. Nonnegative evaluations propose no additional cut. The allocation grid consists of 0, 1, all reported quantile marks and all proposed cuts.
2. Compute a fallback partition from the marks. At step $k$, assign the interval from the previous boundary to the smallest remaining agent's $k/n$ mark to an agent with that mark, breaking ties by fixed labels. Remove that agent. Give the final suffix to the remaining agent.
3. Pick a fresh control point $s$ strictly between 0 and 1 and outside the finite set comprising the grid and the fixed probes. For example, use the first such rational in a predetermined enumeration. Each agent now reports in a sealed vector her prefix value at each interior grid point and at $s$. A control value equal to a negative integer $-k$ selects the residue $k\bmod(n+1)$, and all other values select zero. Sum residues modulo $n+1$.
4. If the sum is zero, return the fallback. Otherwise let its residue designate agent $j$. Among all complete partitions into $n$ nonempty connected grid intervals, with arbitrary assignments to the agents, consider those that every agent weakly prefers to its own fallback piece according to its reported grid values. The fallback is in this finite set. Return one maximizing $j$'s reported utility, using any fixed tie order.

The model permits cut locations computed from reports; Ortega and Segal-Halevi's Cut Middle example similarly cuts at the arithmetic mean of reported cuts. The negative evaluations here convey only single candidate coordinates. The mechanism never asks for an entire valuation. If cut points are required to be direct answers to Cut queries, this construction imposes another difference from that stricter model. [Ortega and Segal-Halevi, §§2, 3.3](https://doi.org/10.1007/s00355-022-01416-4)

## Fallback proportionality

The boundary at stage $k-1$ is at or to the left of every surviving agent's first $(k-1)/n$ crossing. Continuity and the definition of first crossing imply that such an agent's value of this prefix is at most $(k-1)/n$, even when her cumulative value is nonmonotone. Her own next mark is strictly beyond the previous boundary and has cumulative value $k/n$. Thus every winning agent receives at least $1/n$, and the same reasoning at the final boundary gives the remaining agent at least $1/n$. This guarantee applies to an individual truthful agent for any dynamically valid answers of the others. Her truthful second-round evaluations can only permit allocations worth at least her fallback.

## Control of the final role

Fix the first-round history and all payoff-relevant evaluations of an opponent in the second round, consistent with at least one valuation. The opponent can realize any of the control residues without changing these data. To see this, take a continuous piecewise-linear nonnegative bump supported in an arbitrarily small neighborhood of $s$ avoiding the fixed probes, all grid points, and the recorded first crossings. Subtract a suitable positive multiple of this bump from the opponent's cumulative value. This modification cannot create an earlier crossing of a positive threshold, and all the old crossing points are unchanged. It preserves finite variation and the endpoints. There are negative integer codes for every residue arbitrarily far below the original control value. This realizes each role even when the original control evaluation is already very negative.

At a second-round node, the opponent can force fallback regardless of an agent's report. Hence every lie's worst case is at most the true fallback value, and truth guarantees at least this value. For the best case, consider any outcome a lie could attain with given opponents' reports. If it is worth at most the truthful fallback then truth already does at least as well. Otherwise it is an eligible improvement with respect to the agent's true evaluation and the opponents' unchanged grid evaluations. Make this agent the designated maximizer without changing those evaluations. Truth can then realize at least that outcome's true utility. This establishes both NOM comparisons.

## The first-round extremes

For the worst case, fix opponents with the same true valuation as the agent. Regardless of which lie she reports, each truthful opponent receives at least $1/n$ by the individual guarantee. Additivity and total value 1 give her at most $1/n$. Truth always gives her at least $1/n$.

For the best case, fix a true agent and any complete allocation into $n$ nonempty intervals. Its interior boundaries may be perturbed by arbitrarily little to avoid the fixed probes, because all valuations under consideration are continuous. Preserve the ordering of the boundaries. Assign each of the other $n-1$ agents a nonnegative continuous cumulative valuation with its entire mass supported strictly inside its allocated interval. Choose the supporting densities so none of their first $k/n$ crossings land at fixed probes. There is a common fixed probe $p$ that is not one of the true agent's at most $n-1$ quantile marks. The other agents' marks and all candidate boundaries also avoid it. The fallback boundaries, which are drawn only from quantile marks, therefore avoid $p$.

Assign the $n-1$ desired boundaries $b\in(0,1)$ one each to the other agents. For the agent assigned $b$, subtract a downward bump from its cumulative value, supported in a small neighborhood of $p$ avoiding every target boundary and every quantile mark. Choose the coefficient so the new value at $p$ equals $\log b<0$. The original cumulative value was nonnegative, so this is always possible. All quantile marks and all evaluations at the target and fallback boundaries stay unchanged. Each opponent still gets value 1 in the target allocation and its fallback utility is still at most 1. The resulting grid contains the entire target partition. Control the final role to designate the true agent without changing the new payoff-relevant values or first-round reports.

If the true agent prefers its target to its realized fallback, the target is now an admissible improvement for every participant, so the designated true agent gets at least its target utility. If it weakly prefers its fallback, the fallback guarantee already gives it as much. Thus the agent can approach its supremum over *all* complete connected allocations by truthful reporting. No lie can yield an allocation outside that set. For $n=2$ these attainable own pieces are endpoint intervals. For $n\ge3$ they include all interior intervals compatible with a complete partition. For $n=1$ awarding the entire cake is immediate.

## Comparison with separate public rounds

This establishes connectedness, proportionality and NOM for unrestricted $n$ **under the specified sealed-batch semantics**. A public sequential implementation would have interim histories inside both rounds. The public record of earlier quantile marks can restrict the worst outcome of a deviation at such a history. The two-round proof alone gives no inequality at those new nodes. The two-agent result in the companion note uses one scalar query per agent per round and avoids this obstacle.


A separate [public scalar-query mechanism](cake-scalar.md) modifies the eligibility rule to handle these interim histories.
