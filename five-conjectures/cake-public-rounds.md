# Why public quantile rounds cannot simply be serialized

This note audits an attempted arbitrary-population extension of the two-agent protocol. It applies to a specific mechanism architecture. It does not prove impossibility of all Robertson–Webb mechanisms.

Consider the following fallback on three normalized agents. Each supplies the first prefix cuts of values 1/3 and 2/3. Give the prefix up to the smallest first mark to its maker. Of the two survivors, give the middle interval up to the smaller second mark to its maker. Give the suffix to the other. First-hitting cuts guarantee proportionality for signed inputs: each survivor's cumulative value at the first selected point is at most 1/3. A proposed extension lets all agents make further reports and returns a connected Pareto improvement over the fallback according to their reports, including the fallback itself. Assume that on some continuation available to a truthful agent the fallback is selected, as in the construction with an opponent-controlled selector.

If the first-mark answers become public before the second-mark questions, this extension can be obviously manipulated. Take the true agent i to have uniform value. The first marks are 1/10, 1/3 (i), and 17/20 (the other survivor). The other survivor's first 2/3 crossing must occur strictly after 17/20, for every continuous consistent signed valuation. This follows from the intermediate value theorem and the earlier first 1/3 crossing. Therefore i's truthful second mark is 2/3, and i's truthful fallback is the middle interval of length 2/3−1/10 = 17/30. Her worst-case utility cannot exceed 17/30.

Let a=1/10, d=3/4, and ε=1/100. Define i's false cumulative function G by piecewise linear interpolation through (0,0), (a−ε,a−ε), (a,−10), (a+ε,a+ε), (1/3,1/3), (d,2/3), and (1,1). This is a normalized finite nonatomic signed type with exactly the prescribed first 1/3 mark. Its first 2/3 mark is d. The other survivor cannot reach 2/3 that early, so i's reported fallback is [a,d] and G(d)−G(a)=10+2/3.

Whatever final Pareto improvement is returned, its interval [s,t] for i must then satisfy G(t)−G(s) ≥ 10+2/3. Since G(t)≤1, this forces G(s)<0 and hence s<a+ε. Since G(s)≥−10, it forces G(t)≥2/3 and hence t≥d. Her true utility for the final interval is its length, strictly greater than d−a−ε=16/25, which is greater than 17/30. Thus this single consistent lie improves her conditional worst case.

If finitely many auxiliary evaluations were public before that move, one may retain their point values in the interpolation provided none forces an earlier 2/3 crossing or fixes the dip itself. For finitely many fixed prefix probes this can be ensured by choosing the winning mark a off the probes, avoiding them in its arbitrarily small neighborhood, and choosing a sufficiently small gap between the truthful and false second marks. If an auxiliary probe happens to equal 2/3, first monotonically reparametrize the cake to move the true second quantile to an unqueried point. This last extension covers fixed probes. It does not exclude mechanisms that deliberately evaluate the selected winning mark or use different adaptive queries.

Once both grid and fallback are already fixed by the history, subsequent public evaluation queries present a different issue. A selector that can force the fallback and can grant any agent final priority to maximize its reported utility over individually rational grid allocations can make those evaluation queries NOM. Given a deviation, any outcome above the true fallback is also individually rational for i under truth. Fixing the opponents' grid utilities and switching to i-priority allows truthful i to do at least as well as the deviating outcome. Opponents can select fallback to cap the worst payoff of any deviation. This argument presupposes that their selector report can still be varied without changing their earlier reports and grid utilities. It does not cure manipulation while grid and fallback are still being determined.


The [arbitrary-population scalar construction](cake-scalar.md) allows a prefix assignment exempt from the reference-utility constraint. That specific change removes the assumption used by this counterexample.
