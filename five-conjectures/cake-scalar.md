# A connected proportional mixed-cake protocol for arbitrary populations

Research manuscript, November 26, 2026. Status: proof proposed for independent review.

## Theorem

For every finite n ≥ 2, when each agent can have any finite nonatomic signed valuation of the interval with total value 1, there is a deterministic Robertson–Webb mechanism that produces a connected proportional allocation and is not obviously manipulable at every public history. Each active agent answers one ordinary query per node. Interval values are additive, so disjoint boundaries do not affect utilities.

The question is due to [Ortega and Segal-Halevi, §7.2](https://doi.org/10.1007/s00355-022-01416-4). We use their normalization, scalar Cut and Eval queries, and their dynamically consistent public-history NOM definition. A normalized signed type is specified by its continuous bounded-variation cumulative function F, with F(0)=0 and F(1)=1. We restrict to n ≥ 3 in the proof below. A separate four-query mechanism establishes n=2 in [the two-agent proof](cake.md). The type domain allows arbitrary signed, finite, nonatomic measures, without an a priori cap on their negative variation. Section 3.2 specifies the smallest valid cut. Section 7.2 also discusses several locations attaining the same value as possible truthful answers. Our mechanism prescribes the first crossing, following the formal §3.2 query. An oracle that may return any crossing without this prescription is outside this proof. All-agent claims below use the normalization F(1)=1 in §3.1.

## The protocol

Write q=1/n. Break agent ties by increasing label. Whenever a fresh probe is needed, take the first eligible rational in (0,1) in the fixed order by increasing reduced denominator, then numerator.

1. For k=1,...,n−1, simultaneously ask each agent for the first point at which its cumulative value is kq, via Cut(i;0,kq). Publish all answers after each round. Write m_i(k) for the resulting marks and a_i=m_i(1). Each agent's marks are strictly increasing and interior. Define a **reference allocation** B from these marks. For k=1,...,n−1, among the remaining agents choose the one with earliest kth mark, give that agent the interval from the last boundary up to that mark, and remove the agent. Give the remaining suffix to the last agent.
2. Use the n−2 interior points that divide the gap between the largest reported mark and 1 into n−1 equal subintervals as permanent subdivision points. Choose an interior probe p distinct from all marks and subdivisions. Ask every agent one simultaneous Eval(i;0,p). Add the fractional part of each answer as one proposed coordinate. The grid consists of 0, 1, all quantile marks, the subdivision points, and all proposed coordinates. Repetitions coalesce. The probe itself is included only if proposed.
3. In increasing order of all distinct interior grid points g, ask every agent simultaneously for Eval(i;0,g) in its own public round, even if its answer follows from a previous query. Endpoint values 0 and 1 are known. The schedule depends only on the grid. For a full partition X into nondegenerate grid intervals, one per agent, call X eligible if all recipients value their shares at least as highly as in B, with one optional exception: the recipient of the prefix may be exempt if the prefix ends at that recipient's own first mark. Thus an exempt agent gets exactly reported utility q. B is always eligible.
4. Choose a fresh interior point t unequal to p, every quantile mark, and every grid point. Ask simultaneously for Eval(i;0,t). Interpret the sum of the floors of the answers modulo the size of a finite action list. Index B followed by every grid allocation in a fixed order, for instance lexicographic order of the cut indices followed by the recipient permutation. For a selected grid allocation return it if eligible and otherwise return B. The list depends only on the grid, and the value at t is used only for this choice.

**Reference guarantee.** If i wins at stage k, before the preceding selected mark its cumulative value has not exceeded (k−1)q: that boundary is at or before its first (k−1)q mark since i survived that stage. The chosen endpoint is worth kq. Hence i gets at least q. The same reasoning with final endpoint 1 covers the last agent. Successive boundaries increase strictly because surviving agents' kth marks are after their (k−1)th marks. The first winner gets exactly q. Every eligible allocation therefore gives all truthful agents at least q. These statements hold against all dynamically consistent opponent reports.

**Query count.** The grid has at most n(n−1)+(n−2)+n = n²+n−2 interior points. The quantile, proposal, evaluation, and selector rounds thus use at most n(n−1)+n+n(n²+n−2)+n = n³+2n²−n scalar queries in total. The number of grid partitions with g interior points is n! times the binomial coefficient C(g,n−1). The query bound does not assert a comparable running time for enumerating or indexing the partitions.

**An exact three-person example.** Suppose agents 1 and 2 value length uniformly. Let agent 3's cumulative valuation interpolate linearly through (0,0), (1/3,1/3), (2/3,2/3), (5/6,0), and (1,1). All three make the same public quantile marks, so label tie-breaking gives the three equal thirds to agents 1, 2, and 3 in order. Each values its reference share at 1/3. The permanent subdivision point is 5/6. The grid allocation giving agent 2 the first third, agent 1 the interval [1/3,5/6], and agent 3 the suffix [5/6,1] gives respective values 1/3, 1/2, and 1. It is eligible. For any fixed selector reply by agent 2, an opponent's consistent valuation can realize the residue selecting precisely this allocation by a dip at the fresh probe without changing any mark or grid valuation.

## Modifying hypothetical opponents

All modifications below are for constructing possible opponents in the supremum or infimum. They do not ask the actual participants to modify their true types.

At a fresh interior point, an opponent may lower its cumulative value by an arbitrary amount by subtracting a nonnegative piecewise linear triangular function supported in a small neighborhood there. All other finitely prescribed point values are preserved by choosing the support small enough. Preserving each original first quantile mark and decreasing the cumulative function elsewhere preserves each first crossing, since it was strictly below the target at every earlier point. At a fresh point *after all its marks* a bump may also raise its value arbitrarily. These modifications preserve continuity and bounded variation and the endpoint normalization. In particular a single fresh proposal query can encode any desired cut coordinate c in (0,1) by lowering its response to c−K for a suitable positive integer K. At the last probe any opponent can change its floor to any required residue without altering other data or eligibility.

## Decisions after the grid and B are fixed

Condition on an arbitrary history from this phase. All of i's marks, including a_i, arose from the true type at that history, and remain fixed under a compatible deviation. Let b be its true value for B_i, so b≥q. Every truthful eligible outcome gives i at least b, unless it is exempt and receives precisely [0,a_i], worth q.

If some opponent completion permits an eligible i-exempt allocation under truth, that very allocation is eligible for the same opposing grid reports under every deviation by i. The exception makes i's evaluations irrelevant to its eligibility; alternatively it remains eligible when i already prefers its first prefix. An opponent can force that particular allocation at the fresh selector, capping the deviator's worst case at q. Truth guarantees q. If no such completion exists, truth guarantees b, and the forced-reference action caps the deviator's worst case at b.

For the best case, fix any deviation, opponent completion, and its outcome X. If its true utility for i is ≤b, truthful i can obtain B. Otherwise keep all opposing grid values unchanged. X is still eligible under truth: the potential exception for another agent is unchanged, and i values X_i above B_i. An opponent can switch the selector to X itself, so truth can do at least as well. At the selector node itself the same reasoning applies with eligible outcomes already fixed. In all cases the residue can be chosen by an opponent after fixing i's own (possibly deviating) type, with earlier public answers unaffected.

## Decisions before the proposal answers are public

**Conditional worst case.** At the first node, opponents can be clones of i's true valuation. Each of the n−1 clones, reporting truthfully, receives value at least q, even if i deviates, and additivity leaves i at most q. At all later mark nodes, and at the simultaneous p query, a_i is already frozen at its truthful value q. Fix a deviation by i and any consistent completion of all opponents' quantile marks. Consider the grid allocation giving i [0,a_i] and splitting [a_i,1] among its opponents at the n−2 permanent subdivisions. Make this allocation eligible. The first suffix recipient's piece ends at the first subdivision, at which its cumulative value can be raised arbitrarily since all marks precede this point. For each other recipient its left endpoint is a fresh subdivision, and lowering its cumulative value there makes its assigned interval arbitrarily valuable. These modifications change neither the quantiles nor the values of the reference shares, whose endpoints are marks or 0,1. No proposal answer has yet been made public. Any further selector answer can force this eligible allocation, independently of i. Thus no deviation can guarantee more than q.

**Conditional best case, when i won the first reference piece.** Once the first marks are public, i's subsequent marks do not affect B: it was already removed from the reference construction. For any feasible deviation and outcome X, keep the opponents' full quantile data and the same reference allocation. Switching i to truth may give a different grid or a different probe p, but the n−1 opponents can supply all n−1 boundaries of X at the still-unanswered simultaneous probe. To change their proposal responses while preserving their valuations of X and B, first move a boundary of X off the new p if needed. Use an increasing piecewise linear change of spatial coordinate supported in an arbitrarily small neighborhood of the new p, fixing endpoints, opponent marks and all B boundaries. The new p is distinct from those fixed points. Move any X boundary at p slightly, applying the same spatial change to each opposing valuation. This preserves its utility for every transformed X piece and all B pieces, and preserves the first-prefix identity for any exempt opponent. It changes the true value to i of its X piece by arbitrarily little. Now each opponent can lower its value at p without affecting those quantities, thereby proposing one transformed X boundary. If i's true payoff exceeds b by a positive margin, the transformed X is eligible under truth and the selector can choose it directly. If it is at most b, truth can instead attain B. Taking the supremum removes the perturbation.

**Conditional best case, when another agent h won the first reference piece.** Its first mark a_h is the earliest of all first marks and its reference payoff is exactly q. Suppose a deviation by i gives an interval J of true value above q. If J is not a prefix, its left endpoint must be ≥a_h, since a truthful opponent took a complete initial prefix worth at least q in that outcome. The rivals' first marks were frozen when the deviation began. At the initial node, where first marks were not yet public, one can freely choose h with mark a_h earlier than both i's true first mark and the left endpoint of any desired nonprefix J. For a desired prefix one merely chooses a_h earlier than i's mark.

Fix any completions of the opponents' published quantile data and use strictly increasing piecewise linear cumulative functions through their completed marks. Thus the same first marks and the same reference winner h are preserved. Perturb J by arbitrarily little to obtain J' with endpoints distinct from the quantile marks, subdivision points, and p, except for 0 when J is a prefix. When J is nonprefix, take its left endpoint strictly above a_h and its right endpoint strictly below 1, preserving a positive length. This is possible even for a suffix and leaves a nonempty tail. Allocate the entire prefix to h, who values it at least q by monotonicity of the interpolant. Give i J' and subdivide the tail into n−2 positive intervals for the remaining opponents. If J is a prefix, allocate that approximate prefix to i and subdivide the remaining tail into n−1 positive intervals for the opponents. In both constructions choose all tail boundaries to avoid the finitely many protected points. Every tail recipient's left boundary is fresh. Independently lower its cumulative value there so that its assigned piece dominates its fixed reference share in value. These dips need not affect any reference endpoint or the probe. The n−1 opponents can now encode all n−1 interior boundaries through their single simultaneous evaluations at p, using further narrow dips. If i values J' at least as highly as its true reference piece, the whole partition is eligible and the selector can choose it directly. Otherwise the reference piece itself does better. Passing to the limit gives at least the payoff of the original deviation. Payoffs at most q are covered by the unconditional proportional guarantee.

These arguments exhaust the nodes. They use no simultaneous bundle of multiple questions to one agent and require no respondent to encode a valuation in a reply. A proposal reply has an ordinary truthful value and is decoded only as a single cut coordinate. The mechanism uses the unrestricted signed type domain in the attainability arguments; the research claim concerns that mathematical model, not settings with publicly bounded density or bounded negative utility.
